# SVG Editor CLI

TypeScript 面向对象 SVG 命令行编辑器，课程 Lab1 Phase 1。

- [作业提交文档（架构、过程、一致性自查、质量保证）](doc/README.md)
- [原始任务书](phase_cli_1.md)
- 仓库：<https://github.com/R-Morino/svg-editor-cli>

```sh
npm ci
npm run cli
```

输入 `help` 查看命令。运行 `npm run check` 执行格式、类型、测试与架构检查；`npm run build` 构建后可使用 `node dist/src/main.js`。

最终版本为 [`final`](https://github.com/R-Morino/svg-editor-cli/tree/final)，完整说明、过程记录与验证证据均见上方提交文档。
